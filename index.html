Stardew Save Backup

A personal, host-only SMAPI helper that backs up completed Stardew Valley saves to the player's own Google Drive. It creates a local ZIP after a successful save and uploads it in a separate background process. It does not control gameplay.

Privacy policy · Terms of use

Privacy policy

Effective October 19, 2026.

This tool is for personal use. It reads the local game save folder selected by the host and creates a ZIP containing the current save, SaveGameInfo, and supporting mod save data. Backups can include in-game names, farm progress, and other data recorded in the game save.

Google Drive authorization is limited to drive.file: files and folders created by this backup tool. The tool checks that the authorized account matches the configured backup account. It does not request access to unrelated Drive files.

Save archives are transmitted directly from the player's computer to that player's Google Drive. Local archives, retry records, checksums, and upload receipts remain on the player's computer. Credentials are encrypted locally using Windows user protection. No developer-operated server receives save files or credentials.

The tool does not sell data, use advertising or analytics, send saves to an AI model, or use Google user data to train AI models. Data is used only to provide user-requested backup and restore verification. Google API data use follows the Google API Services User Data Policy, including its Limited Use requirements.

The player controls retention and may remove local archives and cloud backups at any time. Existing backups are not automatically made public or shared with other people. Authorization can be revoked through the player's Google Account security settings. Removing the mod stops new scheduled backups; an already-started upload may finish.

For personal-use support or data questions, contact the project owner through this project's GitHub repository. Do not post saves, credentials, or other private information in public issues.

Terms of use

This personal utility is provided as-is without a warranty of uninterrupted service. Google account quota, connectivity, authorization, and the integrity of the original game save can affect backups. Keep independent copies of important saves and verify a backup before restoring it. Use the tool only with saves and storage accounts you are authorized to access. The player remains in control of the account, destination, and stored backups.
